Not features — constraints

  • Authority seam — the extraction contract has no field for a verdict, a severity, or a dose.
  • Structural rule — perception may not import adjudication. The build fails before review.
  • Declared holes — “not in the table” never means “no interaction”.
The model is not asked to behave. It is given no vocabulary.

Six gates, all blocking

  • 1 · test approval + ADR for safety paths
  • 2 · static analysis & structural fitness
  • 3 · requirements schema
  • 4 · semantic evaluation (25 frozen cases)
  • 5 · regression (199 offline tests)
  • 6 · AI-use log — code changed without a record?

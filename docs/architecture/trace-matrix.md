# Trace Matrix

Every requirement maps to **an enforcing component**, **a test that provides evidence**, and **a runtime monitor** that would notice the requirement failing in production. A row with an empty monitor column means the requirement is verified but unobservable — that is a gap, and is flagged as such.

Generated by hand at each sprint close; cross-checked by `test/offline/test_structure.py::test_every_requirement_is_traced`, which fails if a `REQ-*` id in the registry appears in no test file.
